How it works

Order once. Follow every step.

A consistent workflow for ordering sequencing, tracking laboratory progress, and receiving results.

01

Order once

Describe your samples and the sequencing service you need. Jubilab turns your request into a structured order that adapts to each supported provider.

One order, instead of starting from scratch with every lab.

02

Follow every step

See when an order is accepted, when samples arrive, whether they pass QC, when the run starts, and when results are ready, as updates are reported.

Less time spent asking for updates.

03

Get clean results back

Receive a structured result manifest that links output files to your original sample names and includes QC information.

Failed samples are reported explicitly, not silently dropped.

For labs and core facilities

Seamless integration into your existing tools with AI enablement.

Jubilab connects existing lab workflows and does not replace them. Providers can start with a lightweight option and integrate more deeply when it makes sense.

Option 01

Your existing tools

Start with existing order emails and courier information. Email-derived facts are labelled as such, rather than presented as direct confirmation from the lab’s system.

Option 02

A simple status page

Update progress through a lightweight page: received, QC, run started, or results ready. Upload result files without writing a separate status email for every order.

Option 03

Connect your lab software

For deeper integrations, Jubilab takes status updates from laboratory information systems through webhooks, and run progress from instruments.

Keep your tools. Keep your customers. Make the handoffs easier.
Fewer incorrect order sheets, fewer repetitive status requests, and more structured results.

Why we’re building it

Built from a problem we know firsthand.

We run Biligene, a pet genetics testing business. As we coordinate sequencing with outside laboratories, we’ve experienced how much work still happens outside the software.

Orders move through spreadsheets and email. Updates arrive in separate messages. Results need to be mapped back to the samples and workflows that depend on them.

We built Jubilab to solve that operational problem for ourselves, starting with non-clinical genetics sequencing and working toward a consistent interface across laboratories.

“AI can help plan the experiment. Jubilab connects it to the lab that runs it.”

Our own sequencing workflows at Biligene come first, then early-adopter biotech teams and laboratories.
