Guides for tracking how results were made

Short, practical how-tos for bioinformatics teams, with commands you can run on your own files. They are written to be useful without Jubilab, and each one says what it was tested with and when it was last reviewed.

  • How to check which reference genome build a VCF or BAM used

    Read the header with bcftools and samtools, compare contig lengths, test REF alleles, and avoid the chr-prefix and hg19 versus b37 traps.

    Answers: check reference genome build of a VCF

  • What parameters produced this result?

    Find out what a Nextflow, Snakemake or shell run actually used, what gets lost along the way, and what a good record contains.

    Answers: which parameters produced this result

  • Nextflow provenance and lineage: what each tool records

    What Nextflow, Seqera Platform and Snakemake record about a run, from the log to the experimental lineage feature, and where a separate record can help.

    Answers: nextflow provenance

About these guides

Each guide gives a short answer first, then the steps, then what tends to get lost. Commands were run on small synthetic test files where the tools were available, and every guide lists its sources so you can check the official manuals. Where a guide mentions Jubilab, it says where Jubilab is now: building the order-to-result layer for lab work. We are recruiting early adopters, but the order layer is still being built and nothing is released yet.

Found a mistake or a command that no longer works with your version? Email hello@jubilab.io.
